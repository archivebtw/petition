# Обновление с предыдущей версии

1. Сделайте резервную копию текущего проекта.
2. Скопируйте из старого `config.js` ваши `SUPABASE_URL` и `SUPABASE_PUBLISHABLE_KEY` в новый файл.
3. Выполните новый `supabase.sql` в SQL Editor.
4. Замените файлы сайта новой версией.
5. Создайте администратора по инструкции из `README.md`.
6. Turnstile, письма удаления и Edge Functions можно подключить позже: без них основной счётчик и форма продолжают работать через RLS.

Новый SQL не удаляет существующие подписи.
