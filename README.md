# Сайт-петиция «Фонд прямохождения»

Статический адаптивный сайт с записью подписей в Supabase.

## 1. Добавьте логотип

Назовите изображение:

```text
assets/tankzor-logo.jpg
```

Формат: JPG. Рекомендуемое разрешение — минимум 800×800 px. Сайт использует его в шапке и в карточке первого экрана.

## Адаптивность и анимации

- размеры компонентов заданы в `rem`;
- корневой размер шрифта плавно адаптируется к ширине экрана;
- брейкпоинты также заданы в `rem`;
- карточка первого экрана перестраивается под планшеты и телефоны и не перекрывает заголовок;
- верхняя полоса показывает прогресс чтения страницы;
- нативная полоса прокрутки скрыта;
- Lenis 1.3.25 подключён для плавной прокрутки; при блокировке CDN сайт автоматически использует обычную прокрутку;
- анимации отключаются при системной настройке `prefers-reduced-motion`.

## 2. Создайте базу Supabase

1. Создайте проект на Supabase.
2. Откройте **SQL Editor**.
3. Вставьте содержимое `supabase.sql` и нажмите **Run**.

SQL включает Row Level Security:

- посетители могут только добавлять подписи;
- личные данные нельзя читать с публичного ключа;
- наружу доступен только общий счётчик;
- один email может подписать одну петицию только один раз.

## 3. Подключите ключи

Откройте `config.js` и замените:

```js
export const SUPABASE_URL = "https://YOUR-PROJECT.supabase.co";
export const SUPABASE_PUBLISHABLE_KEY = "YOUR-PUBLISHABLE-KEY";
```

Используйте **Publishable key** или старый **anon key**. Никогда не размещайте `secret` / `service_role` key в браузерном коде.

## 4. Запустите локально

ES-модули нельзя надёжно открывать двойным кликом. Запустите локальный сервер из папки проекта:

```bash
npx serve .
```

Или:

```bash
python -m http.server 8080
```

После этого откройте адрес, указанный терминалом.

## 5. Разместите сайт

Папку можно загрузить на Netlify, Vercel, GitHub Pages или любой статический хостинг. Для сборки ничего не требуется.

## Файлы

- `index.html` — структура и текст страницы;
- `styles.css` — дизайн и адаптивная вёрстка;
- `app.js` — форма, Supabase и счётчик;
- `config.js` — публичные настройки проекта;
- `supabase.sql` — таблицы, ограничения, RLS и триггер счётчика;
- `assets/` — изображения сайта.

## Защита от спама

В проекте есть honeypot и локальная задержка между отправками. Для публичной рекламной кампании рекомендуется дополнительно поставить Cloudflare Turnstile и отправлять форму через Supabase Edge Function, чтобы проверка CAPTCHA выполнялась на сервере.
